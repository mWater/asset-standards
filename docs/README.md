# Specification documents

These are the two standards as published, in the form a reader should cite. The
machine-readable tables in `water/` and `sanitation/` are transcribed from these
documents, and where the two disagree, the document governs.

| File | Standard | Version | Issued |
|---|---|---|---|
| `Water-System-Management-Standard-v1.0.pdf` | The Water System Management Standard, Part 1: Asset Management | 1.0 | 2022-04-07 |
| `Sanitation-System-Management-Standard-v1.0.pdf` | The Sanitation System Management Standard, Part 1: Asset Management | 1.0 | 2026-08-21 |

Both are licensed CC BY-SA 4.0 by mWater Foundation, Inc.

Each document opens with its scope, normative references and definitions, then sets
out the data types and units in section 4, the asset classes and types in section 5,
and the attributes in section 6. Section 6.3 explains how to read the attribute
tables, including the formatting convention that separates a group heading from an
attribute from a choice. Anyone transcribing these tables should read that section
first.
